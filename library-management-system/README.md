# Library Atlas

Library Atlas is a React + Vite library management dashboard built with JavaScript, HTML, and CSS.

## Features

- Add, edit, archive, restore, delete, and spotlight books
- Add, edit, deactivate, and remove members
- Issue, return, reserve, and renew books through a circulation panel
- Browser persistence with localStorage
- Search, filter, and sort books, members, and activity
- Overdue tracking and fine estimation
- Export catalog CSV, circulation CSV, and full JSON backup
- Import JSON backups
- Theme toggle with a bold library-inspired UI

## Run it locally

1. Install dependencies:

   `npm install`

2. Start the dev server:

   `npm run dev`

3. Open the local URL shown in the terminal.
