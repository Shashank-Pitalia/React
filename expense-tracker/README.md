# Expense Orbit

Expense Orbit is a polished React expense tracker built with Vite, JavaScript, HTML, and CSS.

## Features

- Add, edit, duplicate, and delete income or expense entries
- Local storage persistence in the browser
- Monthly budget tracking with progress feedback
- Search, filter, and sort transaction history
- Category breakdown and monthly trend panels
- CSV and JSON export
- JSON import support
- Theme toggle with a light and dark mode
- Responsive dashboard layout with a premium visual style

## Run it locally

1. Install dependencies:

   `npm install`

2. Start the dev server:

   `npm run dev`

3. Open the shown localhost URL.

## Notes

- Demo transactions load automatically the first time the app runs.
- Data stays in your browser until you clear it or import a replacement file.
